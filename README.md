# 📚 StudySphere — Your Personal Study Companion

> A study planner and task manager to organise subjects, track deadlines and stay focused.

**Live:** https://project-zero-lab.github.io/studysphere/

**Built by:** Deepanshu Bhatt · Project Zero × Claylab Education Foundation (Cohort 1) · Capstone Project

## What it does
- Plans subjects with chapters, topics and a weekly study schedule
- Manages tasks with priority (High / Medium / Low) and due dates
- Filters tasks by status, subject and priority
- Shows a dashboard with completed vs pending tasks, overall progress and per-subject progress
- Highlights urgent tasks and flags overdue ones
- Includes a Pomodoro focus timer (25 min study / 5 min break)

## How to use
1. Open the live link
2. Go to **Study Planner** → **Add New Subject** and enter chapters and schedule
3. Go to **Task Manager** → **Create Task**, then pick subject, priority and due date
4. Tick a task's checkbox when it's done
5. Check the **Dashboard** for progress and urgent tasks
6. Tap **Focus Timer** to start a study session
